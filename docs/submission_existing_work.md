# Existing Work — Continuity Track Submission

The `StockPredictionMarket` contract (`0x72DAb8B1B53b3CF028e9A0d1E21178981f264245`) has been live on Robinhood Chain Mainnet (Chain ID 4663) since July 3, 2026, with a real on-chain transaction history: 29 `createMarket`, 27 `lockMarket`, 27 `settleMarket`, 3 `placeBet`, and 1 `claimWinnings` call, independently counted via direct JSON-RPC against the chain (commit `da13c80`). Ahead of this submission we added an independent Python reference model that re-derives `settleMarket()`'s price-determination logic and `claimWinnings()`'s payout calculation from the contract's external spec/ABI rather than its implementation, and ran it against all 27 real `settleMarket` transactions and the 1 real `claimWinnings` transaction. All 28 cases match the on-chain outcomes and payouts exactly; the full input/output trace is sealed via a SHA-256 commitment (`verification/settlement/commitments.sha256`). This surfaced two findings, neither triggered by real data to date: the price-read path performs no decimals normalization between the price read at `lockMarket()` and at `settleMarket()` (a latent gap, not an active issue — each market's price feed address is fixed once set); and the README's documented "no winner, full refund" behavior has no corresponding code path in `claimWinnings()` — a fix is planned during the Arbitrum Open House Singapore buildathon. One caveat on coverage: because `settleMarket()` has so far always been called only seconds after `lockMarket()`, all 27 real settlements resolved as exact price ties under the disclosed tie-defaults-to-BULL rule; the reference model correctly validates this path but has not yet been exercised against a settlement decided by genuine price movement.
